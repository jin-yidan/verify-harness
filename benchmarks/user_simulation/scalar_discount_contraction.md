# Claimed Theorem

For real numbers `x` and `y`, if `0 ≤ γ`, then

`|γx - γy| ≤ γ |x - y|`.

This is the scalar inequality underlying the nonexpansive part of the
discounted Bellman contraction argument.

# Submitted Proof

Factor the difference:

`γx - γy = γ(x-y)`.

Taking absolute values gives

`|γx - γy| = |γ| |x-y|`.

Since `0 ≤ γ`, we have `|γ| = γ`. Hence

`|γx - γy| = γ |x-y|`,

which implies the claimed inequality.
